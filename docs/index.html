Bedrock Linux -AOK

Run 29 Linux distributions simultaneously on iOS through iSH-AOK. Mix and match packages across distros with chroot-based strata.

v1.3.0 · GPLv2 · aarch64 · 2 editions · 29 distros
View on GitHub

Features

Everything you need to run multiple Linux distributions on iOS.

29 Distributions

Alpine, Debian, Ubuntu, Fedora, Arch, Kali, Gentoo, Void, openSUSE, and 20 more — all running side by side.

Two Editions

Reversible (brl) and permanent (bedrockport.sh) — both with the full feature set. Clean uninstaller included.

Capability Detection

Probes iSH-AOK runtime capabilities — namespaces, cgroups, bind mounts — and adapts automatically.

Safe Rollback

Create snapshots before changes. Roll back if something goes wrong. Health checks verify stratum integrity.

Cross-Distro Packages

Use apt from Debian, pacman from Arch, dnf from Fedora in the same session. Mix packages freely.

Integration Layer

systemd boot units, AOK roots registration, structured logging, and a full self-test suite.

Editions

Two editions, both with the full feature set. Choose reversible or permanent.

Reversible
brl
  • Full stratum management
  • Cross-distro commands
  • Integration layer
  • Reversible with brl unhijack
  • Does not persist across reboots
Permanent
bedrockport.sh
  • Full stratum management
  • Cross-distro commands
  • Integration layer
  • Survives reboots
  • --hijack / --update / --restat
  • Recommended for new installs
Use brl-uninstall to remove a permanent install. The reversible edition supports brl unhijack.

Quick Start

Get running in under a minute.

# Download the unified installer wget https://raw.githubusercontent.com/vjnzbcsbgf-maker/Bedrock-AOK/main/bedrockport.sh chmod +x bedrockport.sh # Install (hijack mode) ./bedrockport.sh --hijack # Fetch a stratum and use it brl fetch alpine strat alpine apk add htop # List all installed strata brl list
